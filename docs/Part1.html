1.5 Vérification des données manquantes

corona_dataset_aggregated.isnull().sum().sum()
np.int64(0)

La fonction isnull() est utilisée pour vérifier la présence de valeurs manquantes dans le DataFrame corona_dataset_aggregated. La méthode sum() est appliquée deux fois pour obtenir le nombre total de valeurs manquantes dans l’ensemble du DataFrame. Si le résultat est 0, cela signifie qu’il n’y a aucune valeur manquante dans les données agrégées par pays. Et avec la fonction sum() permet de compter le nombre de valeurs manquantes pour chaque colonne en additionnant les valeurs True (1) et False (0) dans chaque colonne. En appliquant sum() à l’ensemble du DataFrame, on obtient le nombre total de valeurs manquantes dans toutes les colonnes combinées.

Et, on obient np.int64(0) qui indique qu’il n’y a aucune valeur manquante dans le DataFrame corona_dataset_aggregated après l’agrégation par pays. Cela signifie que toutes les données sont complètes et qu’il n’y a pas de valeurs manquantes à traiter dans ce DataFrame agrégé. Par conséquent, on peut procéder à l’analyse des données sans se soucier des valeurs manquantes.

1.6 Vérification des doublons

corona_dataset_aggregated.duplicated().sum()
np.int64(0)

la fonction duplicated() qui retoure un table de booléens indiquant si une ligne est un doublon ou non. En appliquant sum() à ce résultat, on obtient le nombre total de lignes dupliquées dans le DataFrame corona_dataset_aggregated. Si le résultat est 0, cela signifie qu’il n’y a aucune ligne dupliquée dans les données agrégées par pays. Cela indique que chaque pays est représenté une seule fois dans le DataFrame, ce qui est important pour garantir l’intégrité des données et éviter les biais dans l’analyse.
